# Shopify Bulk Optimization

Use when auditing multiple Shopify product pages from a product CSV or preparing a reviewed batch of text/SEO changes. For one product, use `shopify-product-page-automation` instead. For AI-written copy, use `shopify-ai-copy-generation`.

## Tools
- `tools/shopify_bulk_feed.py`
- `docs/shopify-bulk-feed-optimization.md`
- Synthetic example: `examples/shopify_bulk_feed_sample.csv`

Run commands from the **repository root** with Python 3.10+.

## Workflow
1. Confirm the catalog export is authorized. Run offline: `python3 tools/shopify_bulk_feed.py analyze --input examples/shopify_bulk_feed_sample.csv --output /tmp/shopify-bulk-audit.json`.
2. Review the JSON findings and conservative SEO drafts. They are not AI-generated. Variant/image rows are grouped by handle, which is **not** a Shopify Product ID.
3. To prepare for live Shopify changes, verify the exact numeric Product IDs or GIDs from the merchant's authorized Shopify records; place them in a private JSON array.
4. With locally managed `SHOPIFY_SHOP_DOMAIN` and `SHOPIFY_ACCESS_TOKEN` (authorized `read_products` and `write_products` scopes as applicable), run `python3 tools/shopify_bulk_feed.py prepare --input /private/product-ids.json --output /private/review-manifest.json`.
5. Review every product and proposed change against verified source facts. Remove unapproved entries. Mark `approved: true` only for precisely authorized changes.
6. After explicit approval, run `python3 tools/shopify_bulk_feed.py apply --input /private/review-manifest.json --output /private/new-update-log.jsonl --confirm --limit 25`.
7. Re-fetch updated products, verify output and inspect the private JSONL log, especially after partial failures.

## Guardrails
- `apply` performs **live Shopify writes**. Never treat `--confirm` as authorization on its own.
- Changes are limited to title, description HTML and SEO metadata; never change price, inventory, variants or publication.
- Respect snapshot hashes and output-file uniqueness; batches are non-atomic with **no automatic rollback**.
- Never commit private merchant exports, OAuth/API credentials or operational logs.
- Do not claim that CSV suggestions are generated by AI.
